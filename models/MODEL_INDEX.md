## Total Assets
- **7 models** total

- **All models** in glTF 2.0 format
- **Modular design** - character and clothing can be mixed and matched
- **Colorful clothing** - Multiple color options available

## Quick Start
1. Load the human character: `models/character/human_lowpoly.gltf`
2. Add clothing items from the `models/clothing/` directory
3. Mix and match different colored clothing items
4. Gray clothing can be customized, colored items have preset colors
